# Tree

## Traversal(遍歷)

## BFS（Breadth First Search）廣度優先搜尋
1. level-order traversal 層序遍歷

2. BFS優點
    * 適合尋找最短路徑（Shortest Path）
    * 適合找最近的節點（Closer nodes）

3. BFS缺點
    * 需用到較多的記憶體（More Memory）




## DFS（Depth First Search）深度優先搜尋

1. preorder traversal 前序遍歷
2. inorder traversal 中序遍歷
3. postorder traversal 後序遍歷


4. DFS 優點
    * 較省記憶體（Less Memory）
    * 適合確認路線是否存在（Does Path Exist ?）

5. DFS 缺點
    * 若 tree or graph 很深，效率不彰（Can get slow）
